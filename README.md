# Гамма 40

Звук и свет для мозга в браузере: три режима.

- **Очистка** — стимуляция 40 Гц (протокол GENUS, MIT): импульсы 10 кГц по 1 мс каждые 25 мс и мерцание экрана, три уровня.
- **Отдых** — альфа, тета и дельта-биения под ведомое дыхание.
- **Видения** — Ганцфельд: ровный цветной свет без мерцания и коричневый шум.

Открыть: https://andreysuperfly.github.io/gamma40/

Не медицинское изделие. Мерцание опасно при фоточувствительной эпилепсии. Источники — во вкладке «О методе».
